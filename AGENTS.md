# Repository workflow

- Treat each completed user-requested framework change as one version.
- Verify the change, make one scoped commit with a descriptive message, and push it to `origin/main`.
- Do not commit generated projects or conversation data to this framework repository.
- Generated apps belong in `/home/gmagogsfm/kiddo_projects`; the supervisor approves and names each app update before the server commits it.
- Keep `chat.json` local and out of Git history.
